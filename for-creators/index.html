01

動かす — 思いついた自動化を、数日で。

自分の現場で「これは面倒だ」と感じた瞬間に、そのまま作る。企画書もベンダー選定も挟まない距離の近さが、この14本を生みました。うち7本は、いま・この場で・ブラウザから触れます。

父のための議事録 話した内容を、あとから読み返せる記録に。 Live Demo メール → 週報 埋もれたスレッドを、報告の形に整える。 Live Demo 議事録 → 週報 会議メモから、そのまま週報の下書きへ。 Live Demo スマホのタスク管理 毎朝の段取りを、スマホでひと目に。 Live Demo AI電話一次受付 かかってきた電話の一次対応を、AIが受ける。 Live Demo 商品説明文づくり 商品情報から、説明文の案を量産する。 Live Demo 画像・FAX自動整理 届いた紙や画像を、自動で仕分けて名前を付ける。 Live Demo

内製ツール14本のうち、公開できる7本。自分の実務のために作り、いまも動いています（デモは模擬データで、その場で触れます）。

02

納める — 趣味と本物の、境目を越える。

「動いた」と「業務で使われている」の間には、深い溝があります。検収・運用・保守——その溝を越えて納めた案件が、信用の背骨です。

03

巻き取る — 映像の量産を、システムにする。

冒頭のリリックMVは、手作業のタイミング打ちをしていません。曲から完成まで、一本の自作パイプラインが通っています。縦動画の量産も同じ思想です。

P-1Suno で楽曲生成AIで曲そのものをつくる
P-2歌詞タイミング自動採取音声認識で一語ずつ拾う
P-3自作システムで同期歌詞と映像をコードで束ねる
P-4リリックMV 完成縦動画の量産にも同じ型を

企画と台本は、プロと組みたい。
私が巻き取るのは、量産・多言語化・素材生成という「重い部分」です。

作品の核——世界観・演出・言葉選び——はあなたのもの。それを百本規模へ量産する仕組み、多言語化、締切の逆算——その「重い側」を引き受けます。

Handoff  —  渡し合いの図

取り合わない。渡し合う。

企画も世界観も、あなたの手に残ります。私は、動くところだけを引き受けます。
── ただし待ってはいません。面白いと思ったら、頼まれる前に作って持っていきます。

あなたから渡すもの

  • 企画・世界観・演出核はあなたの手に残したまま
  • デザインカンプ・ラフ・絵コンテ精度は問いません。走り書きでも
  • 「これ、動かせない？」の一言入口はこれで十分です

私から渡すもの

  • 数日で触れる、動くプロトタイプ会議より先に、現物を置きます
  • 頼まれる前に作ったもの面白いと思ったら、先に持っていきます
  • 量産と自動化の仕組み一回きりで終わらせない
  • 検収して引き渡せる納品物運用を見据えた引き渡しまで

たとえば、こんな渡し方

  1. Design → BuildLPやツールのデザインカンプを、動くWebと業務の自動化まで。
  2. Concept → VolumeMV・縦動画の企画を、歌詞同期・多言語化・量産パイプラインへ。
  3. Idea → Demo展示やイベントの構想を、その場で触れるデモ・受付システムに。
