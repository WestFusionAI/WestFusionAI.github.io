本アドオンは、寸法・公差・図面情報・計算結果を開発者の外部サーバーへ送信または保存しません。

1. 取得する情報

West Fusion AI（以下「開発者」）が提供する「公差スタックレビュー」（以下「本アドオン」）は、利用者情報、Googleアカウント情報、スプレッドシートの内容、寸法、公差、図面情報、計算結果を開発者の外部サーバーへ送信または保存しません。広告識別子、アクセス解析、利用追跡も使用しません。

2. Googleユーザーデータの利用

利用者が開いているGoogle Sheets内で、利用者の操作に応じて入力シートと解析結果を作成・更新するためだけに、現在のスプレッドシートへのアクセス権限を使用します。データを広告、信用評価、AI学習、第三者提供に使用しません。

3. 外部送信と第三者提供

外部API、Gmail送信、外部データベースを使用せず、利用者の入力情報を開発者または第三者へ送信しません。開発者が内容を人手で閲覧することもありません。

4. 保存と削除

作成情報は利用者のGoogle Sheets内に保存され、開発者側には複製を保持しません。アンインストール後も作成済みのシートと計算結果は残ります。削除する場合は、利用者が対象シートまたはスプレッドシートを削除してください。

5. 権限

開いているスプレッドシートの読み書きとアドオン画面の表示に必要な権限だけを要求します。Google Drive全体、Gmail、連絡先、カレンダーへアクセスしません。

6. セキュリティ

外部送信・外部保存を行わず、Apps Scriptの例外ログも無効にする設計です。利用者は所属組織のGoogle Workspace管理規程と共有設定に従い、機密情報を適切に管理してください。

7. 子どもの利用

本アドオンは業務上の機械設計を対象としており、子ども向けサービスではありません。

8. 変更

機能または情報取扱いを変更する場合は本ページを更新します。外部送信や新たなデータ利用を追加する場合は、必要な説明と同意を行います。

9. Google API Services User Data Policy

本アドオンによるGoogle APIから受け取った情報の使用および他のアプリへの転送は、Google API Services User Data Policy（Limited Use要件を含む）に準拠します。
